# Azure PaaS Lab

Azure PaaSでの実験等を再現可能なコード・Bicep・技術記事に育てる学習ラボです。

Azure PaaSの構成や動作を検証し、その結果と設計上の判断をまとめます。検証に使用したコードやIaCも公開し、同じテーマに取り組む方が手元の環境で試せる形を目指します。

## コンテンツ

- **検証記録**：検証の目的、構成、手順、結果、考察
- **サンプルコード**：検証に使用したアプリケーション
- **IaC（Bicep）**：検証環境を再現するための構成定義
- **技術記事**：検証から得た知見や、構成・実装を選ぶ際の判断材料

## 検証・記事一覧

現在準備中です。公開した成果をテーマ別に整理し、検証記録・コード・関連記事へのリンクを追加していきます。

GitHub Pagesは成果の一覧と各コンテンツへの入口、Zennは知見をまとめた技術記事の公開先として整備する予定です。

## 検証テーマ・質問

検証予定のテーマや進捗は[Issues](https://github.com/yuuuuukou/azure-paas-lab/issues)で管理します。検証内容に関する質問や改善案もこちらへお願いします。
